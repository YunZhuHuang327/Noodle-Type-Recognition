# 模型準確率提升改進總結

本文件記錄了所有實作的改進措施，預期可提升模型準確率。

## 已實作改進清單

### 1. 測試時增強（TTA - Test Time Augmentation）
**檔案**: `predict.py`
**預期提升**: 1-3%

**改進內容**:
- 新增 `get_tta_transforms()` 函數，提供 3 種不同的測試轉換
- 新增 `predict_test_set_with_tta()` 函數，使用多種增強方式預測後平均結果
- 在 `main()` 中添加 `USE_TTA` 開關（預設啟用）

**使用方式**:
```python
# 在 predict.py 中設定
USE_TTA = True  # 啟用 TTA
USE_TTA = False # 關閉 TTA（標準預測）
```

---

### 2. 優化器改用 AdamW
**檔案**: `train.py:275`
**預期提升**: 3-8%

**改進內容**:
- 將 SGD 優化器改為 AdamW
- 學習率設為 0.001，權重衰減 0.01
- AdamW 通常比 SGD 收斂更快且更穩定

**參數**:
```python
optimizer = optim.AdamW(model.parameters(), lr=0.001, weight_decay=0.01)
```

---

### 3. 改進資料增強策略
**檔案**: `train.py:47-63`
**預期提升**: 3-5%

**改進內容**:
- 增加裁剪多樣性：scale=(0.8, 1.0)
- 增加旋轉角度：15 度
- 增強色彩變化：brightness, contrast, saturation=0.2
- **新增平移增強**: RandomAffine translate=(0.1, 0.1)
- 降低隨機擦除機率：0.2（避免過度增強）

---

### 4. 調整 Dropout 率
**檔案**: `resnet18_model.py:81`
**預期提升**: 1-2%

**改進內容**:
- 從 0.5 降至 0.3
- 避免過度正則化導致欠擬合
- 在數據量充足時，較低的 Dropout 率更適合

---

### 5. 調整驗證集比例
**檔案**: `train.py:52`
**預期提升**: 1-2%

**改進內容**:
- 從 15% 降至 10%
- 增加訓練數據量
- 提供更多樣本供模型學習

---

### 6. MixUp 資料增強
**檔案**: `train.py:24-44, 160-172`
**預期提升**: 2-4%

**改進內容**:
- 新增 `mixup_data()` 和 `mixup_criterion()` 函數
- 在訓練循環中整合 MixUp
- alpha=0.2 控制混合程度
- 提升模型泛化能力，減少過擬合

**使用方式**:
```python
# train_model() 函數參數
use_mixup=True  # 啟用 MixUp
use_mixup=False # 關閉 MixUp
```

---

### 7. Cosine Annealing 學習率調度器
**檔案**: `train.py:318-320, 213`
**預期提升**: 1-3%

**改進內容**:
- 使用 CosineAnnealingLR 替代 ReduceLROnPlateau
- 實現平滑的學習率衰減
- 避免學習率突然下降造成的訓練不穩定
- eta_min=1e-6 確保學習率不會過小

## 使用建議

### 訓練流程
1. 運行 `train.py` 進行訓練
2. 所有改進預設已啟用
3. 觀察訓練過程中的驗證準確率

### 預測流程
1. 使用訓練好的模型 `best_resnet18_noodles.pth`
2. 運行 `predict.py`
3. TTA 預設啟用，會自動使用 3 種增強方式

### 參數調整建議
如果模型出現過擬合（訓練準確率 >> 驗證準確率）:
- 增加 Dropout 至 0.4-0.5
- 增加 weight_decay
- 增強資料增強強度

如果模型出現欠擬合（訓練準確率和驗證準確率都不高）:
- 降低 Dropout 至 0.2
- 減少資料增強強度
- 增加訓練 epochs

---

## 注意事項

1. **MixUp** 會讓訓練準確率看起來較低（正常現象），但驗證準確率會提升
2. **TTA** 會讓預測時間增加約 3 倍，但準確率會提升
3. **AdamW** 學習率通常設為 0.001，比 SGD 的學習率小
4. **Cosine Annealing** 會在訓練過程中持續降低學習率
